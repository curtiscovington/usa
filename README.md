# USA Flag

A full-screen, animated United States flag for [usa.curtiscovington.com](https://usa.curtiscovington.com).

The flag is drawn procedurally and rendered as a premium Canvas 2D cloth surface. It has no runtime dependencies and respects the operating system's reduced-motion preference.

## Local preview

```bash
npm run dev
```

## Production build

```bash
npm run build
```

GitHub Actions publishes `dist/` to GitHub Pages on every push to `main`.
